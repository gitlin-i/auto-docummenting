# 데이터 저장 후 수동 실행 방식

## 개요
웹 프론트엔드에서 데이터를 입력하고, JSON 파일로 저장한 후, Python 스크립트를 수동으로 실행하는 방식입니다.

## 장점
- 서버 불필요
- 모든 환경에서 실행 가능
- 간단한 설정
- `win32com.client` 사용 가능 (Windows)

## 단점
- 수동 단계 필요
- 자동화되지 않음

## 사용 방법

### 1. 웹에서 데이터 입력
1. `npm start`로 React 앱 실행
2. http://localhost:3000 접속
3. 매니저 정보, 스케줄 등 입력
4. 파일 저장 (📂 열기 또는 📄 새로 만들기)

### 2. 데이터 내보내기
1. "📊 데이터 내보내기" 섹션에서 "💾 Python용 데이터 저장" 클릭
2. JSON 파일이 다운로드됨 (예: `calendar_data_2024-12-20T10-30-45.json`)

### 3. Python 스크립트 실행
```bash
# 방법 A: 최신 JSON 파일 자동 사용
python hwp_generator.py

# 방법 B: 특정 JSON 파일 지정
python hwp_generator.py calendar_data_2024-12-20T10-30-45.json
```

## 파일 구조
```
project/
├── calendar-app/           # React 웹 앱
│   ├── src/
│   │   ├── components/
│   │   │   ├── DataExporter.js    # 데이터 내보내기 컴포넌트
│   │   │   └── DataExporter.css
│   │   └── App.js
│   └── package.json
├── hwp_generator.py        # HWP 생성기 (JSON 지원)
├── hwp-app/

└── calendar_data_*.json    # 웹에서 저장된 데이터
```

## JSON 데이터 형식
```json

    {"name": "김단아"},
    {"name": "문주원"},
    {"name": "박석진"},
    {"name": "서은영"}
  ],

    "overtimeSchedules": {},

    "targetMonth": "2025-03"

  "version": "1.0"
}
```

## 문제 해결

### 1. JSON 파일을 찾을 수 없음
- 웹에서 데이터를 저장했는지 확인
- JSON 파일이 Python 스크립트와 같은 폴더에 있는지 확인
- 파일명이 `calendar_data_*.json` 형식인지 확인

### 2. HWP 초기화 실패
- 한글 오피스가 설치되어 있는지 확인
- Windows 환경인지 확인
- 한글 오피스가 실행 중이면 종료 후 재시도

### 3. 템플릿 파일 오류
- `hwp-app/청년이룸출근부.hwp` 파일이 존재하는지 확인
- 템플릿 파일에 치환할 텍스트가 포함되어 있는지 확인

### 4. 권한 오류
- Python 스크립트 실행 권한 확인
- 출력 폴더에 쓰기 권한 확인

## 웹어셈블리 방식과의 차이점

| 구분 | 웹어셈블리 방식 | 데이터 저장 방식 |
|------|----------------|-----------------|
| 실행 환경 | 브라우저 | 로컬 Python |
| HWP 생성 | 불가능 | 가능 (Windows) |
| 자동화 | 완전 자동 | 수동 단계 필요 |
| 서버 | 불필요 | 불필요 |
| 라이브러리 제한 | 있음 | 없음 |

## 권장 사용 시나리오

1. **Windows 환경 + HWP 생성 필요**: 데이터 저장 방식 사용
2. **다른 OS 또는 HWP 불필요**: 웹어셈블리 방식 사용
3. **개발/테스트**: 웹어셈블리 방식 사용
4. **실제 배포**: 데이터 저장 방식 사용

## 추가 기능

### 자동 JSON 파일 찾기
스크립트가 자동으로 가장 최신의 `calendar_data_*.json` 파일을 찾아서 사용합니다.

### 명령행 인수 지원
```bash
# 특정 JSON 파일 지정
python hwp_generator.py my_data.json

# 최신 파일 자동 사용
python hwp_generator.py
```

### 오류 처리
- JSON 파일이 없으면 기본 설정으로 실행
- HWP 초기화 실패 시 상세한 오류 메시지
- 각 단계별 진행 상황 출력
