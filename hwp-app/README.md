# HWP Generator - 웹어셈블리 버전

## 개요
React 앱에서 웹어셈블리를 사용하여 Python 스크립트를 실행하고 HWP 파일을 생성하는 기능입니다.

## 기능

### 1. Python 스크립트 (`hwp_generator.py`)
- 기존 Python 코드를 분석하여 작성된 HWP 파일 생성기
- 각 매니저별로 개별 HWP 파일 생성
- 파일명 형식: `청년이룸출근부_매니저이름_YYMM.hwp`

### 2. 웹어셈블리 Python 러너 (`hwpPythonRunner.js`)
- Pyodide를 사용하여 브라우저에서 Python 코드 실행
- HWP 파일 생성 로직을 웹어셈블리로 시뮬레이션
- 텍스트 파일로 다운로드 가능

## 사용 방법

### 1. React 앱에서 사용
```javascript
// HwpButtons 컴포넌트 사용
<HwpButtons 
  managers={managers}
  savedData={savedCalendarData}
  currentDate={new Date()}
/>
```

### 2. Python 테스트
- "Python 테스트" 버튼을 클릭하여 웹어셈블리 환경 확인
- Python 버전과 기본 기능 테스트

### 3. HWP 파일 생성
- "HWP 파일 생성" 버튼을 클릭
- 각 매니저별로 텍스트 파일이 자동 다운로드
- 파일명: `청년이룸출근부_매니저이름_YYMM.txt`

## Python 코드 분석

### 기존 코드 분석 결과
1. **HwpProcessor 클래스**: 한글 오피스 COM 객체 제어
2. **MetaData 클래스**: 파일 경로, 날짜 등 메타데이터 관리
3. **EroomManagerSchedule 클래스**: 매니저별 스케줄 관리
4. **generate_replace_dict 함수**: 치환 데이터 생성

### 웹어셈블리 구현
- 브라우저에서 실행 가능한 Python 로직 구현
- 실제 HWP 파일 대신 텍스트 파일로 시뮬레이션
- 동일한 치환 로직 적용

## 치환 데이터

각 매니저별로 다음 데이터가 치환됩니다:
- `%Name`: 매니저 이름
- `%Year`: 연도
- `%Month`: 월
- `%Endday`: 해당 월의 마지막 날
- `%일1`, `%일2`: "월/일"

## 예시 출력

### 생성되는 파일명
- `청년이룸출근부_김단아_2503.txt`
- `청년이룸출근부_문주원_2503.txt`
- `청년이룸출근부_박석진_2503.txt`
- `청년이룸출근부_서은영_2503.txt`

### 파일 내용 예시
```
청년이룸 출근부

매니저: 김단아
대상 월: 2025-03
연도: 2025
월: 3
마지막 날: 31

치환 데이터:
- %Name: 김단아
- %Year: 2025
- %Month: 3
- %Endday: 31
- %일1: 월/일
- %일2: 월/일

이 파일은 HWP 템플릿에서 생성되었습니다.
실제 HWP 파일을 생성하려면 한글 오피스가 필요합니다.
```

## 장점

1. **서버 불필요**: 별도의 Python 서버 없이 브라우저에서 직접 실행
2. **크로스 플랫폼**: 모든 브라우저에서 동작
3. **보안**: 클라이언트 사이드에서 실행되어 보안성 향상
4. **실시간**: 즉시 실행 결과 확인 가능
5. **파일 다운로드**: 생성된 파일을 브라우저에서 직접 다운로드

## 주의사항

1. **네트워크 연결**: Pyodide 로딩을 위해 인터넷 연결 필요
2. **브라우저 지원**: 최신 브라우저에서만 동작
3. **실제 HWP 파일**: 브라우저에서는 텍스트 파일로만 생성 가능
4. **한글 오피스**: 실제 HWP 파일 생성에는 한글 오피스 설치 필요

## 향후 개선 사항

1. **실제 HWP 파일 생성**: 서버 사이드에서 실제 HWP 파일 생성
