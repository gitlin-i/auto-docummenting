# 간단한 HWP 생성기 사용법

## 개요
웹 브라우저에서 데이터를 입력하면 `calendar_data.json` 파일에 저장되고, Python 스크립트가 이 파일을 읽어서 HWP 파일을 생성합니다.

## 파일 구조
```
청년이룸출근부_데이터/
├── 청년이룸출근부_데이터.json   # 웹에서 저장된 데이터
├── 청년이룸출근부.hwp          # 템플릿 파일
├── hwp_generator.py           # Python 스크립트
└── 청년이룸출근부_*.hwp        # 생성된 HWP 파일들
```

## 사용 방법

### 1. 웹에서 데이터 입력
1. React 앱 실행: `npm start`
2. http://localhost:3000 접속
3. 매니저 정보, 스케줄 등 입력
4. 파일 저장 (📂 열기 또는 📄 새로 만들기)

### 2. Python 스크립트 실행
```bash
python hwp_generator.py
```

```

```

## 주의사항

1. **파일 위치**: 모든 파일이 같은 폴더에 있어야 합니다
2. **템플릿 파일**: `청년이룸출근부.hwp` 이름으로 고정
3. **데이터 파일**: `청년이룸출근부_데이터.json` 이름으로 고정
4. **Windows 환경**: 한글 오피스가 설치되어 있어야 합니다
5. **일자 자동 조정**: endday에 맞춰서 31, 30, 29, 28일이 자동으로 제거됩니다
6. **빗금 자동 추가**: 근무하지 않는 날(일요일, 대체휴무일, 토요일 근무가 아닌 토요일)에 해당하는 날짜를 표의 "%일1"과 "%일2" 열에서 찾아 우측 5칸(출근, 결근, 지각/조퇴, 근로자, 담당)에 좌하단에서 우상단으로 가는 빗금이 자동으로 추가됩니다. 각 매니저별로 개별적인 근무 스케줄과 대체휴무일이 적용됩니다. 텍스트 치환 전에 수행되어 원본 텍스트를 기준으로 처리됩니다

## 문제 해결

### 1. 청년이룸출근부_데이터.json 파일이 없음
- 웹에서 데이터를 저장했는지 확인
- 파일이 Python 스크립트와 같은 폴더에 있는지 확인

### 2. 청년이룸출근부.hwp 파일이 없음
- 템플릿 파일이 Python 스크립트와 같은 폴더에 있는지 확인

### 3. HWP 초기화 실패
- 한글 오피스가 설치되어 있는지 확인
- Windows 환경인지 확인
